## 🔄 如何隨時自動更新 591 物件？（未來新增或下架物件時）

未來當您在 591 店鋪上有新上架房屋、降價調整或成交下架時，**完全不需要手動修改程式碼**：

1. 到桌面打開 **`群義房屋-個人形象網頁`** 資料夾。
2. 對著 **`更新591最新物件.bat`** 連按兩下執行。
3. 程式會自動連線至您的 591 店鋪（代號: `45609`），將目前在售的**所有物件（包含價格、坪數、格局、高畫質照片、專屬 591 連結）**全部自動抓取並更新到網頁中！
4. 打開或重新整理 `index.html` 即可看到最新物件清單！
